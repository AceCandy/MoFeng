可借鉴亮点（按优先级）

  • 【P0】Sudowrite — Story Bible 集中化+注入式生成：角色/设定/风格集中一处，每章生成时按需注入 Style/Characters/Scenes，并做 continuity sweep。启发：MoFeng 已有蓝图，可借鉴"生成时自动选片注入+生成后一致性扫描"闭环。
  • 【P0】妙笔生花 WordFlower — 显式 RAG 记忆+"半自动原则"：内置 RAG 追踪人物/剧情/场景，主打千章连贯；明确"AI 不编造设定，只做格式化/质检/推荐"。启发：这是最贴身的直接竞品，建议作为头号对标，逐功能对照其大纲/章纲/续写/润色/拆书链路。
  • 【P1】Novelcrafter — Codex 记忆+Scene Beats+BYOK：人物/地点/物件做成可被上下文自动引用的条目；节拍盒让作者只写"接下来发生什么"。启发：伏笔/角色/世界观做成"可自动引用条目"；开放 BYOK 给重度用户降本。
  • 【P1】NovelAI — Lorebook 关键词触发+TTS/图像一体化：条目按关键词触发注入（省 token、防冗余）。启发：借鉴触发策略优化 RAG 成本与命中率，只在出现相关名词时带入设定。
  • 【P1】AutoCrit / Inkfluence AI — 独立的一致性与 plot hole 检查：把找剧情漏洞/时间线/动机矛盾做成独立检查。启发：六维审查可显式拆出一致性/伏笔/时间线专项并给可定位修订建议，形成差异化卖点。
  • 【P1】Sudowrite — Canvas+Describe+Rewrite：Canvas 集中收藏灵感并生成备选情节点；Describe 按五感输出；Rewrite 一次给多候选。启发：灵感孵化做成分版本可沉淀空间；五感模板融入情绪/描写维度审查。
  • 【P2】阅文作家助手 — 平台化：消息触达/书评/月票/全端同步。启发：若面向"平台作者"可轻量接入读者反馈/数据看板；纯工具路线可忽略。

MoFeng 的差异化优势

  • 多版本生成+评审选版做成结构化闭环：竞品里只有 Sudowrite Rewrite 给多候选、彩云小梦做版本回退，但都缺"生成多版→评审→选版"闭环。MoFeng 把评审选版作为一等公民。
  • 六维质量审查与一致性体系化：多数竞品只有零散 consistency check 或被动注入，MoFeng 的"六维"更体系化。
  • 伏笔（foreshadowing）作为独立实体管理：调研对象中未发现将"伏笔"单独建库并追踪埋设/回收的产品（待核实），潜在强差异点。
  • 管理后台/治理层：所有 C 端竞品均无后台治理概念，MoFeng 面向"平台"具备 B 端/团队治理空间。
  • LangGraph 多智能体架构：天然适合把"蓝图→生成→评审"拆成多 agent 协作，比单 prompt 类工具更有扩展空间。

Top 5 可借鉴建议（按优先级）

  • 【P0】对标 WordFlower，逐功能对照并强化"评审选版"差异——把大纲→章纲→续写→润色→拆书链路逐一对照，确保在"多版本评审选版+六维质量审查"上保持明显领先，这是最直接的护城河。
  • 【P0】把蓝图/世界观/角色/伏笔做成"生成时自动注入+生成后一致性扫描"闭环——借鉴 Story Bible 与 Codex，结构化设定不只是给人看，而是自动选片喂入每次生成。
  • 【P1】RAG 上下文采用"关键词触发注入"以控成本——借鉴 Lorebook 触发策略，避免全量注入爆 token，对长篇连载成本与命中率有直接收益。
  • 【P1】六维质量审查显式拆出"一致性/伏笔/时间线/情绪"专项，并给可定位修订建议——借鉴 AutoCrit 把 plot hole/时间线做成独立可执行检查，让"质量护栏"成为对外卖点。
  • 【P2】开放 BYOK 与灵感板 Canvas——重度用户用 BYOK 降本（Novelcrafter 模式）；灵感孵化阶段做成"可分版本、可沉淀参考"的空间，补齐创作流程最前端。

拾壹差异化与战略

把审查结论收拢到三条战略主线——这是决定 MoFeng 下一程走向的判断。

  • 主线一 · 护城河强化：多版本评审选版 + 六维质量审查 + 伏笔独立追踪，是对抗 WordFlower/Sudowrite 的核心，必须保持明显领先。下一步把"生成时自动注入设定 + 生成后一致性扫描"做成闭环，让结构化蓝图真正喂进每一次生成。
  • 主线二 · 工程基线补齐：13 个 P0 里 8 个是"安全 + 工程纪律"欠债（CORS/SSRF/密钥明文/无 Alembic/分层越界/鉴权重复）。不补则"单人能跑、多人会痛、上线即危"。这是从作品到产品的必经一关。
  • 主线三 · 品牌回归：PRODUCT.md 的定位准确（安静、专业、克制），但实现系统性跑偏（古风印章作功能标识 + 持续装饰动效 + 高饱和渐变）。回归"功能词为主、古风为辅"，让界面重新像一张"可靠的写作台"。
