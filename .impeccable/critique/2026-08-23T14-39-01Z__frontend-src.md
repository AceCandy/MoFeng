## Design Specificity Verdict

界面明显为墨风量身设计：群青结构舞台、冷白工作面、荧黄当前动作、朱红发送 cue，加上章节编号与创作状态，无法无损套用到普通 SaaS。问题不在“太普通”，而在新视觉世界没有完全清退旧的熟宣、金石、印章和水墨语法；同一套页面同时存在两套设计合同，且已经造成真实 CSS 级联缺陷。

机械检测 `detect.mjs --json frontend/src` 返回 `[]`。稳定状态下，9 个主页面移动端 axe WCAG A/AA 均为 0 个确认违规，且无页面级横向溢出。桌面项目详情、写作台和管理详情的项目上下文顶栏存在确认的颜色对比度违规。

## Overall Impression

第一眼已经有竞赛级辨识度，响应式也不是简单缩小桌面版。离“顶级”差的不是再加视觉效果，而是一次删除优先的收口：清掉旧视觉合同、修复共享顶栏与账户菜单、补齐页面语义身份。

## What's Working

- 工作台的“当前作品—继续写作—项目档案”层级明确；荧黄唯一主动作与群青舞台有强记忆点。
- 移动写作台默认关闭 100 章目录抽屉，首屏直接展示当前章与恢复动作；412×915 下没有横向溢出，所有可见业务触控项达到约 44px。
- 项目、设置与后台采用连续工作面而不是卡片墙；登录与注册在移动端仍保持清晰节奏。

## Priority Issues

### [P1] 全站账户菜单无法通过键盘打开

- **Why it matters**：`div role="button"` 的 `tabIndex=-1`，没有 Enter/Space 键盘处理；键盘与部分辅助技术用户无法进入个人设置、修改密码和退出登录。
- **Evidence**：`frontend/src/components/shared/AppShell.vue:543-550`；菜单内 4 个动作还使用 `href="javascript:void(0)"`，见 `:566-615`。
- **Fix**：触发器改为原生 `<button>`；菜单动作也改为 `<button>`，补 Escape 关闭与焦点恢复。
- **Suggested command**：`$impeccable audit`

### [P1] 桌面项目上下文顶栏不满足 WCAG AA 对比度

- **Why it matters**：题材、进度、章节数和用户名是持续导航上下文，却出现 1.08–2.03:1 的对比度，远低于 4.5:1。
- **Evidence**：axe 在项目详情/管理详情确认 5 个节点，写作台确认 2 个节点；旧 scoped 规则位于 `frontend/src/components/shared/AppShell.vue:928-1010`，覆盖了 `frontend/src/assets/styles/components/world-class.css:287-303` 的白字舞台合同。
- **Fix**：删除旧“纸色项目上下文”覆盖，让状态胶囊、数字和用户信息统一继承白色/荧黄；不要再叠加一层更高 specificity。
- **Suggested command**：`$impeccable audit`

### [P2] 单一视觉合同仍未真正收口

- **Why it matters**：登录标题的“印”、工作台“墨进度”、章节状态“钤/描/墨”和概览“成/待”仍属于被 DESIGN 明确淘汰的印章/仿古语法，削弱剧场提示本方向。
- **Evidence**：`frontend/src/views/Login.vue:15-19`、`frontend/src/views/NovelWorkspace.vue:127-130`、`frontend/src/components/writing-desk/WDSidebar.vue:550-559`、`frontend/src/components/novel-detail/OverviewSection.vue:219-246`。
- **Fix**：保留群青、编号、cue 线和文字状态；删除装饰性单字章与旧术语。
- **Suggested command**：`$impeccable quieter`

### [P2] 核心页面缺少稳定的语义身份

- **Why it matters**：工作台、灵感、写作台和设置页没有 `<h1>`；所有路由的 `document.title` 都只是“墨风”，屏幕阅读器、标签页切换和历史记录难以区分页面。
- **Evidence**：`frontend/src/views/NovelWorkspace.vue:68`、`frontend/src/views/InspirationMode.vue:15-23`、`frontend/src/components/writing-desk/workspace/ChapterMeta.vue:5`、`frontend/src/views/SettingsView.vue:7`；静态标题在 `frontend/index.html:8`。
- **Fix**：不改变视觉字号，补一个页面级 h1；用现有 route meta label 设置 `墨风 · 页面名`。
- **Suggested command**：`$impeccable audit`

### [P2] 入口 CSS 已无安全余量

- **Why it matters**：入口 CSS 为 25.97KB / 26KB，仅剩约 0.03KB；任何“再加一层 override”的修复都可能直接触发硬预算失败。
- **Evidence**：`npm run build:budget` 新鲜通过但给出单文件预警；旧 visual layer 与新 `world-class.css` 仍并存。
- **Fix**：后续修复必须以删除旧 scoped/legacy 规则为主，再做必要的最小替换。
- **Suggested command**：`$impeccable distill`

## Persona Red Flags

- **Sam（键盘/屏幕阅读器用户）**：无法聚焦账户入口；4 个核心工作页缺少 h1；桌面项目上下文信息对比度失败。
- **Casey（移动碎片写作者）**：移动布局本轮表现良好，章节抽屉默认关闭、业务触控项约 44px；设置页较长但分组清晰。
- **长期连载作者**：最近作品、章节搜索与当前恢复动作都有效；“钤/描/墨”等状态仍需要额外解码，不如直接状态词高效。

## Minor Observations

- 初次加载时 1.2 秒 `fadeIn` 会让 axe 短暂报告欢迎语对比度；动画结束后该项为 0 违规，归为瞬态信号，不列真实缺陷。
- 登录/注册按钮的伪元素背景使 axe 无法自动判定若干对比度项，属于 incomplete，不是确认违规。
- 浏览器控制台未发现稳定复现的页面错误；夹具缺少 `POST /api/novels` 导致的灵感创建错误不代表生产 API 故障。
