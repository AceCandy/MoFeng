# 全部前端页面逐页精修：技术方案

## Boundaries

改动限定在前端页面、现有共享壳/组件、样式、最小回归测试与现有 E2E fixture。保持路由、API、数据结构、鉴权规则和业务流程不变，不新增依赖或视觉体系。

本任务是一次 refinement：先在当前浏览器中复验历史 P2 与页面状态，再在最窄正确归属处修复。共享问题进入现有 token/共享组件；局部问题留在所属页面。

## Coverage Matrix

| `/workspace` | 加载、空态、有项目、删除弹窗 | 移动 hero 高度、单一主动作、项目下一步 |
| `/inspiration` | 初始、恢复、对话、退出确认 | 项目/阶段身份、移动自动聚焦、退出说明 |
| `/projects/:id` | 8 个详情分区、编辑/新增弹窗 | 长梗概分段、移动回看、分区一致性 |
| `/projects/:id/write` | 目录、稿纸、工作流、助手抽屉 | 章节搜索/跳转、助手信息披露、长目录效率 |

## Interaction Design

### 认证页

- 保留 `AuthIntro`、表单纸卡和现有认证接口；移动端压缩引子占高，让主要表单动作更早进入首屏。
- 注册从单一字符串错误改为字段级错误映射；每个控件只关联自己的 `aria-invalid` / `aria-describedby`，提交失败聚焦首个错误字段。
- 在字段旁展示仓库已有约束的简短帮助；不发明新密码或用户名规则。
- 不实现找回密码后端。登录失败区仅提供真实可执行说明：重试并联系部署管理员，不放置假链接。

### 工作台与灵感

- 工作台移动 hero 保留当前项目与进度，压缩装饰/次要统计；一个状态驱动主动作，创建书卷降为次动作。项目卡继续由同一项目状态派生标签和去向。
- 灵感恢复态在现有 `currentProject` 上显示项目名与当前阶段；移动端不强制聚焦输入，避免软键盘遮挡。退出确认准确区分已发送内容会保留、未发送输入不会保存。

### 项目详情与写作台

- `OverviewSection` 将 `full_synopsis` 按原始空行/换行渲染为多个段落，不改变存储内容。
- `WDSidebar` 增加一个本地章节检索框，同时匹配章节号与标题；无结果显示明确空态。选择结果仍复用现有 `selectChapter` 与滚动逻辑，不新增导航状态源。
- `WDAssistantPanel` 在未定稿章使用原生 disclosure/按钮语义，让一个信息组默认展开；完成章的实际内容梳理保持直接展示。

### 设置与管理

- 设置页只修复浏览器中仍可复现的 URL、ARIA、密度与状态问题，继续由现有 section query 和脏状态守卫拥有导航。
- `PromptManagement` 增加本地搜索，匹配 name/title/tags；桌面保持双栏，移动端在“列表”和“编辑”两面之间切换。编辑面返回列表时组件不卸载，未保存内容不丢失；切换到另一 Prompt 仍走现有脏状态确认。
- 管理详情完成标记使用可读文本/状态容器，不依赖对普通 `span` 无效的 `aria-label`。

## Responsive And Accessibility Contract

- 基准视口为 `1440×900` 与 `390×844`；共享壳、详情和写作台额外抽查 833/834 与 1199/1200 边界。
- 原生输入、按钮、`details/summary` 或现有组件优先；触控目标不低于 44px，焦点环使用现有 token。
- 搜索无结果、字段错误、加载/空态/错误/禁用/权限状态必须有可见文本和可访问名称。
- 只使用 `--md-*` / `--ink-*` 暖纸 token，保持颜色权责、字族、纸页柔影与单主题合同。

## Browser And Test Strategy

- 复用现有 `e2e-fixture-server.mjs`，只补九页渲染所需的最小确定性数据/管理员场景，不建立第二套 mock 层。
- 新交互使用现有 Vitest/Vue 测试方式补最小行为合同；页面级响应式、axe、溢出和导航用 Playwright/agent-browser 验收。
- Impeccable 采用一次初审、一次集中修复、最多一次复验。截图、报告、浏览器状态和测试产物均为临时证据，不提交。

## Risks And Rollback

- 字段级校验容易与后端错误混淆：客户端只定位已知本地规则，服务端通用错误继续显示在表单级提示。
- 搜索过滤可能隐藏当前选中项：查询清空后恢复全量列表；编辑状态不因过滤或移动返回被销毁。
- 共享样式可能影响九页以外的弹层：只修改已有共享规则的根因，浏览器复验全部九页。
- 所有变更为前端可回滚改动；按认证、创作、设置/管理三个批次可独立撤回。
