# 修复全站复审遗留问题

## Goal

以删除旧视觉合同为主，修复全站复审确认的共享界面缺陷，使单一浅色“剧场排演提示本”皮肤在键盘操作、颜色对比度、视觉语言和页面语义上保持一致。

## Background

- 复审报告：`.impeccable/critique/2026-08-23T14-39-01Z__frontend-src.md`，综合 31/40，确认 2 个 P1、3 类 P2 收口问题。
- 9 个主路由在稳定状态下无已确认的移动端 axe A/AA 违规和页面级横向溢出；桌面项目上下文顶栏存在 1.08–2.03:1 的确认对比度失败。
- 浏览器复核确认写作台实际渲染链未使用 `WDHeader.vue`，真实章节标题仍为 `h2`；项目档案、认证页和管理页已有页面标题。
- 移动写作台的长章节目录已默认收起；灵感 fixture 缺少 `POST /api/novels` 不代表生产故障，二者均不属于本任务。

## Requirements

### R1. 账户菜单原生键盘合同

- 将账户入口由不可聚焦的 `div role="button"` 改为原生按钮，保留当前外观、44px 触控尺寸和点击外部关闭行为。
- 菜单中的系统管理、提示词用量、个人设置、修改密码改为原生按钮，彻底移除 `javascript:` 链接。
- 公开 `aria-expanded` 与 `aria-controls`；菜单内按 Escape 后关闭菜单并把焦点恢复到触发器。

### R2. 项目上下文顶栏对比度

- 删除 `AppShell.vue` 中与全局群青白字合同冲突的旧纸色 scoped 覆盖，不新增更高 specificity 的补丁。
- 项目详情、写作台和管理详情的题材、进度、章节数及账户信息在桌面稳定状态下满足 WCAG 2.1 AA 文本对比度。

### R3. 单一视觉语言收口

- 登录页删除装饰性“印”及其孤立样式。
- 工作台把“墨进度”改为“项目进度”，删除进度端点的印章式装饰及其孤立样式。
- 章节侧栏删除“钤/描/墨”状态方印及其专用状态映射和样式；保留现有状态点、Tooltip 和屏幕阅读器状态文本。
- 项目概览把压缩状态“成/待”改为“完成/待补”，保留现有完整状态语义。

### R4. 页面语义身份

- 工作台、灵感页、写作台和独立设置页各提供一个页面级 `h1`，不改变既有视觉字号；设置弹窗继续使用 `h2`，避免嵌入 AppShell 时重复页面标题。
- 复用现有路由 `meta.label` 设置标签页标题，格式为“页面名 · 墨风”；为登录和注册补齐 label，未知页面回退为“墨风”。

### R5. 体积与兼容性约束

- 入口 CSS 不增加净体积，优先删除旧 scoped/legacy 规则。
- 不新增依赖，不修改后端、API、路由路径、权限规则、数据结构或业务流程。
- 保留单一浅色皮肤，不新增主题切换或暗色分支。

## Acceptance Criteria

- [x] 账户入口可通过 Tab 聚焦，并由原生 Enter/Space 激活；Escape 关闭菜单并恢复触发器焦点，源码中不再有 `href="javascript:void(0)"`。
- [x] 项目详情、写作台、管理详情的桌面项目上下文顶栏通过稳定状态 axe WCAG A/AA 检查，不再出现已确认的颜色对比度违规。
- [x] 运行界面和相关源码不再包含本任务列出的“印”“墨进度”“钤/描/墨”状态方印；概览显示“完成/待补”。
- [x] 9 个主路由均有正确页面级标题结构；设置页作为独立路由是 `h1`，作为弹窗是 `h2`；写作台真实章节标题是唯一 `h1`。
- [x] 具名路由导航后 `document.title` 为“页面名 · 墨风”，登录/注册分别为“登录 · 墨风”“注册 · 墨风”。
- [x] 前端类型检查、lint、完整单元测试、生产构建和 26KB CSS 硬预算通过；Impeccable detector 返回空结果。
- [x] 9 个主路由在 1440×900 与 412×915 下完成一次集中复核：无页面级横向溢出、无新增确认 axe A/AA 违规，账户菜单键盘路径通过。
- [x] 调试过程中启动的所有服务和浏览器会话在结束前关闭，不保留截图、缓存或临时调试产物。

## Out of Scope

- 重新设计页面信息架构、设置页动作分组或新增视觉效果。
- 修复仅由 E2E fixture 缺失造成的灵感创建失败。
- 为动态项目名或章节名新增异步标签页标题。
- 清理与上述确认缺陷无关的历史 CSS、注释或业务代码。

## Risks

- 删除项目上下文 scoped 样式可能暴露全局规则未覆盖的局部元素；以三个受影响路由的桌面浏览器复核为准。
- `SettingsView` 同时作为路由和弹窗使用，标题标签必须按 `isModal` 分支验证。
- 入口 CSS 已接近硬预算；任何必要样式调整必须由同批删除量覆盖。
