# 全站顶级视觉重设计

## 目标

把墨风现有九个主页面从“暖纸仿古精修”升级为一套可展示、可辨认、适合长期创作的完整视觉世界。视觉重构必须服务于作者迅速恢复项目上下文、确认下一步和持续写作，不能以装饰牺牲操作清晰度。

## 范围

- 重设计 `NovelWorkspace`、`InspirationMode`、`NovelDetail` / `AdminNovelDetail` 共享详情壳、`WritingDesk`、`Login`、`Register`、`AdminView`、`SettingsView`。
- 重设计 `AppShell`、`AuthLayout`、全局设计令牌、按钮/表单/弹层/导航等共享视觉基础。
- 保持唯一一套浅色皮肤，不恢复暗色主题，不出现大块近黑背景。
- 为每个页面建立与核心任务对应的专属构图，同时维持同一设计系统。

## 视觉承诺

- 采用“剧场排演提示本”世界：群青是结构舞台，冷白是长时工作面，朱红是关键 cue，荧黄只用于临时批注。
- 把 AI 表达为提示、候选和排演，把作者确认表达为正式落场；状态不能只靠颜色区分。
- 拒绝旧版暖宣纸、印章、书法、仿古双线框，也拒绝通用白色 SaaS 卡片墙。
- 使用现代中文无衬线正文与收窄展示字形，优先现有字体和浏览器原生能力，不新增 UI 依赖。

## 必须保持

- 后端 API、数据结构、鉴权、路由、查询缓存和业务流程不变。
- 登录、注册、OAuth、管理员强制改密、模型配置、未保存确认、创作生成、章节版本、朗读与任务提醒等既有行为不退化。
- 保留测试依赖的稳定 class、ARIA 文案和 1200 / 834 / 833 响应式契约；确需改变时同步最小测试契约。
- 不虚构指标、用户、模型状态或产品能力。

## 验收标准

- [x] 九个主页面及管理员详情共享壳全部进入同一新视觉世界，不残留成片暖纸/印章/书法旧主题。
- [x] 工作区首屏清楚显示当前项目、下一步和唯一主动作；项目库可快速扫读。
- [x] 灵感页以对话为主舞台，辅助脉络在桌面可见、窄屏可收起，不伪装成真实提取结果。
- [x] 详情页、章节列表和写作台维持高密度但层级明确，长文阅读面不被装饰干扰。
- [x] 登录强调“继续创作”，注册强调“建立身份”，两页不再只是同构表单换标题。
- [x] 设置页突出能力与模型路由关系；管理后台突出系统状态与任务导航。
- [x] 桌面 1440×900 与 Pixel 7 尺寸下无横向溢出、关键操作可达、触控目标不小于 44px。
- [x] 键盘焦点、错误反馈、对比度和 `prefers-reduced-motion` 满足 WCAG 2.1 AA 基础要求。
- [x] 不新增前端依赖，不修改后端代码；生产构建、类型检查、现有单元测试和相关 E2E 通过。
- [x] 完成桌面/移动两轮以内的真实浏览器截图复验、一次机械检测和独立视觉/功能复核。
- [ ] 最终 `DESIGN.md` 按实际实现重写，工作提交、任务归档和 journal 均完成。

## 非目标

- 不新增协作、离线、发布、付费等产品功能。
- 不重构后端或重写前端状态管理。
- 不引入 WebGL、音效或与日常写作无关的炫技。
