# 修复全局状态间距与稳定性

## Goal

修复项目卡状态线贴字、焦点伪选中、候选标签选中跳动、灵感条目缩放和项目选择语义问题。

## Requirements

- 保留现有群青结构面、冷白工作面和项目库视觉冲击，不改变页面信息架构。
- 项目卡状态线与内容之间必须保留稳定间距；键盘焦点不得伪装成整行选中态。
- 候选版本、灵感条目和顶栏项目项切换状态时不得改变文字或容器几何位置。
- 顶栏项目下拉中的当前项目必须暴露可访问的当前项语义。
- 仅修改已确认的问题及对应回归断言，不新增组件、依赖或设计令牌。

## Acceptance Criteria

- [x] 项目卡在桌面与移动端 hover 时左侧状态线不贴标题，内部按钮获得焦点时只保留控件自身焦点提示。
- [x] 候选版本标签选中前后 padding、border 和 display 占位一致，长标签不引发内容跳动。
- [x] 灵感条目激活前后不再缩放，背景、边框和印章仍能表达进度状态。
- [x] 顶栏项目项常态预留透明边框，当前项目带有 `aria-current`。
- [x] 相关单元回归测试、前端类型检查和 lint 通过；浏览器桌面与移动端复测无横向溢出。

## Notes

- 本任务是局部 CSS 状态稳定性与模板语义修复，采用 PRD-only 轻量流程。
