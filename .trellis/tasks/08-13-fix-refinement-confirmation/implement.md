# 修复润色后重复选版：实施计划

1. 在 `NovelService` 的章节公开投影中加入待确认候选收敛逻辑。
   - 只识别 `metadata.ai_review.is_best is True`。
   - 仅恰有一个优选版本时筛选；否则兼容回退全量版本。
   - 验证：后端测试覆盖优选为第二版、无标记回退、历史版本仍完整。
2. 调整 `ChapterWorkflowPanel` 单候选状态的显示语义。
   - 单候选不渲染多版本选择控件，直接展示润色结果并允许确认现有版本 ID。
   - 多候选兼容路径保持现有选择和键盘行为。
   - 验证：组件测试覆盖单候选确认、多候选回退及真实 ID 提交。
3. 独立复核数据流与改动范围。
   - 运行后端聚焦测试。
   - 运行前端组件测试和类型检查；若全量命令受环境限制，记录未验证项。
   - 检查生成合同无变化、工作区无临时产物、diff 只涉及本需求。

## Rollback Point

本修复不迁移数据。回滚产品代码和对应测试即可恢复原行为。
