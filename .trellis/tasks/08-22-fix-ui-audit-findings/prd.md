# 修复并美化页面审查问题

## Goal

修复 2026-08-22 九份页面审查报告中仍可复现的 P0/P1 问题，使用户能信任页面状态、不会静默丢失编辑、在 390px 移动端完成核心流程，并达到 WCAG 2.1 AA 基础要求；视觉修正保持现有“描红界格”设计世界，不做整站重设计。

## Background

- 审查覆盖 `/login`、`/register`、`/workspace`、`/inspiration`、`/projects/:id`、`/projects/:id/write`、`/settings`、`/admin`、`/admin/novels/:id`。
- 报告合计 4 个 P0、22 个 P1，存放于 `.impeccable/critique/2026-08-22*.md`。
- 当前工作树只有上述 9 份未跟踪审查报告；它们必须原样保留。
- 代码复核确认部分审查项已具备实现或当前已不再复现：写作台已有唯一 H1，注册验证码字段当前前后端一致。这些项目只补回归验证，不制造重复改动。

## Requirements

### R1 安全配置不回显

- 管理系统配置的 list/get/upsert/patch 响应不得返回敏感配置原值。
- 敏感键至少覆盖 API key、password、secret、credential、private key 等明确秘密语义，不能把 `max_tokens` 之类普通配置误判为秘密。
- 响应明确告知前端该项是否敏感；敏感项仅显示“已配置/未配置”，编辑时留空表示保留原值。
- 不在日志、测试失败信息、示例、报告或 DOM 中复述真实秘密值。

### R2 写作状态与移动工作区可信

- 已完成章节在被选中、工作流空闲或恢复期间仍显示“已完成”，不得出现“开始生成”误导动作。
- 390px 宽度下写作台不横向溢出；目录与辅助面板互斥，关闭面板从键盘和辅助技术树中移除。
- 保留现有桌面三栏契约和 833/834/1199/1200 断点。

### R3 项目详情核心路径可达

- 普通用户在移动/窄屏能打开分区导航并看到明确的继续写作入口。
- 导航加入已经实现的“章节”分区，普通用户与管理员均可进入；章节列表图标按钮有可访问名称。
- 页面只有一个 H1，分区切换写入 `section` query，并支持刷新、前进和后退恢复。

### R4 防止静默丢失编辑

- 设置页阶段路由有未保存修改时，切换设置分区或离开页面前必须保存、放弃或取消离开。
- Prompt 编辑有未保存修改时，切换 Prompt、切换管理分区或离开页面前必须确认；保存后恢复干净状态。

### R5 管理数据与危险操作可靠

- 管理项目详情通过已有管理员详情接口加载完整项目，不把缺失字段兜底成角色 0、章节 0/0。
- 管理统计加载时显示骨架或占位符，不先呈现具有真实数据外观的 0。
- 用户启用/禁用等即时生效的危险开关具有可访问名称，并在写入前确认。

### R6 认证、工作台与灵感流程

- 登录页移除没有会话语义的“记住我”死控件；登录和注册各只保留一个 `<main>` 地标。
- 注册现有前后端约束以合同测试锁定，不新增仓库中不存在的规则。
- 工作台 CTA 文案与实际去向一致；删除弹窗背景不可聚焦、不可被辅助技术读取。
- 灵感“重新开始”必须清除当前未完成灵感项目后创建新会话；删除失败时保留旧会话并显示错误。

### R7 可访问性与相关视觉整理

- 修复报告指出的低对比小字、删除操作、风险提示和未激活词笺；正文文本达到 4.5:1，大号文本达到 3:1。
- 修复写作工具栏菜单关联、详情内部滚动区键盘可达、重复/错误标题层级。
- 移动设置页将大量阶段路由压缩为可展开分组，默认只展开当前相关组；桌面保持高效总览。
- 使用现有颜色、间距、按钮、纸页和界格 token，不引入新依赖、不改变产品视觉世界。

## Acceptance Criteria

- [x] AC1：后端针对敏感配置的 GET/PUT/PATCH 测试证明响应中不含提交或存储的秘密原值，非敏感配置仍可正常读取和编辑。
- [x] AC2：前端敏感配置只展示配置状态，编辑时留空保留、输入新值才更新。
- [x] AC3：完成章在选中且工作流 `idle` 时仍显示完成态且没有生成 CTA；对应最小回归测试通过。
- [x] AC4：390×844 下写作台与项目详情 `scrollWidth <= innerWidth`，同一时刻最多一个抽屉可见，关闭抽屉不可聚焦且 `aria-hidden/inert` 正确。
- [x] AC5：项目详情“章节”入口、移动导航、继续写作 CTA、唯一 H1 与 `?section=` 刷新/前进/后退全部可用。
- [x] AC6：设置路由和 Prompt 编辑在切换/离开时不会静默丢失；确认取消后保持原编辑内容。
- [x] AC7：灵感重开后旧未完成项目不再被恢复，新会话只显示初始引导；删除失败时旧内容不丢失。
- [x] AC8：管理详情显示与已有管理员项目接口一致的角色数和章节进度，并可巡检章节正文；加载期不显示假 0。
- [x] AC9：登录/注册没有嵌套 main；危险开关有可访问名称和确认；报告中的低对比节点通过 axe/WCAG AA 检查。
- [x] AC10：前端类型检查、相关 Vitest、相关后端 Pytest、OpenAPI/生成类型检查、Impeccable detector 均通过。
- [x] AC11：桌面与移动浏览器回归覆盖 9 个页面，无新增控制台错误、横向溢出或临时产物。

## Out of Scope

- 不实现新的“记住我”长期会话协议；当前删除无效控件。
- 不进行系统配置历史值的批量加密迁移或数据库结构变更；敏感项的新写入遵循现有 Fernet 规则，历史明文由兼容解密逻辑继续读取。
- 不代替运维轮换已经暴露的凭证；交付时明确提醒轮换。
- 不修改与报告无关的业务流程、文案或设计系统，不新增依赖，不重构邻近代码。
- 不为已经不可复现且现有合同一致的审查项制造代码变更。

## Key Decisions Requiring Final Approval

- 登录“记住我”选择删除，不扩展 token 生命周期和跨端会话语义。
- 美化选择局部 polish：对比度、层级、密度、移动布局与交互状态，不做重设计。
- 九个页面作为一个集成任务分批实现；共享导航、弹窗、管理查询等根因跨页复用，不拆成额外任务树。
