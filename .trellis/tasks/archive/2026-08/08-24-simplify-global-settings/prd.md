# 重构全局导航与设置体系

## Goal

让作者从全局导航进入设置时获得稳定、可返回、可深链的页面体验；把首次可用配置与低频高级配置分层，并消除设置大弹窗及其内部多级弹窗造成的认知、焦点和滚动问题。

## Background

- `AppShell.vue:585-691` 的账户菜单混合系统管理、提示词用量、个人 AI 设置、修改密码与退出登录。
- `AppShell.vue:732-791` 用多个 `GlobalModalContainer` 承载设置、管理、提示词和密码；其中 `SettingsView` 同时也是 `/settings` 路由页面，形成双宿主。
- `SettingsView.vue:164-169` 现有文本生成、记忆检索、语音朗读、阶段路由四个能力分区，可继续复用。
- `PersonalModelRouting.vue:96-113` 在设置宿主内继续打开 `ModelPickerDialog`；浏览器审查确认会形成设置弹窗上的第二层浮层。
- 配置数据流审查未发现可安全断言为“前后端均无消费者”的用户可编辑字段；问题主要是低频配置暴露过早、入口重复和职责混合。
- 审查快照：`.impeccable/critique/2026-08-24T09-27-19Z__frontend-src-views-settingsview-vue.md`。

## Requirements

### R1. 全局导航收口

- 账户菜单只提供清晰的一层入口：AI 设置、账户与安全、管理后台（仅管理员）和退出登录。
- “提示词用量”归入管理后台，不再作为个人账户菜单中的独立入口。
- 设置与管理入口使用稳定路由，不再从全局导航打开大型业务弹窗。
- 任务日志不在本任务中重构，保持现有行为。

### R2. 设置页面化

- 复用现有 `/settings` 与 `SettingsView` 作为唯一 AI 设置宿主。
- 取消 `SettingsView` 的全局弹窗宿主及外层重复保存/关闭控制。
- 分区状态可通过 URL 恢复，并支持浏览器前进、后退和刷新。
- 页面关闭或切换分区时继续保护未保存修改。

### R3. 基础配置与高级配置分层

- 首次可用路径优先呈现：连接供应商、选择文本主模型、选择记忆检索模型。
- 语音朗读仅在用户需要该能力时进入，不与首次文本配置争夺首屏。
- 阶段路由、模型定价、自定义供应商参数归为高级配置或按需展开。
- 阶段路由以“继承主模型”为默认心智，只突出显式覆盖项。
- 不删除仍有运行时消费者的配置字段，不改后端配置合同。

### R4. 消除多级弹窗

- 供应商编辑与模型选择在设置页面同一导航层级内完成，不再在大型设置弹窗上继续叠加业务弹窗。
- 仅删除、放弃未保存修改等破坏性操作允许使用确认对话框。
- 关闭内联编辑或选择后，键盘焦点返回触发位置；移动端不出现双滚动上下文。

### R5. 文案与重复入口

- 统一使用“AI 设置”作为全局入口与页面名称；能力分区保留具体业务名称。
- 删除空状态和顶栏重复的“新增供应商”主入口。
- 供应商启停保留一个明确的主要操作路径，避免卡片和编辑表单同权重复。
- 清理 `pending-tts-model-name` 未声明 Prop 造成的 Vue 运行时告警。

### R6. 保持现有合同

- 保持供应商、用户模型、默认 chat/embedding/TTS 模型、阶段路由和定价 API 合同不变。
- 保持 TTS 音色与语速由章节朗读控件管理，不重新放入模型设置。
- 保持账户权限、管理员可见性、退出登录、删除确认和未保存保护。
- 管理员强制改密必须导航到真实存在的账户安全页面，不能继续指向不存在的 `/admin?tab=password` 分区。
- 保持 WCAG 2.1 AA 基础、44px 触控目标、键盘可操作和中文优先。

## Acceptance Criteria

- [ ] AC1：普通用户账户菜单仅显示 AI 设置、账户与安全、退出登录；管理员额外显示管理后台，提示词用量不再独立出现。
- [ ] AC2：从账户菜单选择 AI 设置后导航到 `/settings`，不会创建“个人设置”全局弹窗。
- [ ] AC3：`/settings` 的当前分区可由 URL 恢复，刷新和浏览器前进/后退保持正确内容。
- [ ] AC4：首次进入设置能在一个页面层级内判断缺少的基础步骤，并完成供应商、文本主模型和检索模型配置。
- [ ] AC5：语音朗读、阶段路由、模型定价和自定义连接参数不与基础配置同权占据首屏；仍可明确访问。
- [ ] AC6：模型选择与供应商编辑不产生设置弹窗上的第二层业务对话框；破坏性确认仍保留。
- [ ] AC7：切换分区、离开设置和取消编辑不会静默丢失未保存修改，焦点返回可预测。
- [ ] AC8：桌面与 Pixel 7 视口无横向溢出、无双滚动陷阱；键盘可完成账户菜单到设置核心路径。
- [ ] AC9：打开模型选择流程时浏览器控制台不再出现 `pending-tts-model-name` 未声明 Prop 告警。
- [ ] AC10：现有 LLM 配置 API、TTS 运行时偏好、阶段路由语义和管理员权限合同保持不变。
- [ ] AC11：相关单测、类型检查、lint、构建预算及设置/导航 E2E 通过。
- [ ] AC12：管理员登录后需要强制改密时进入 `/account/security`，完成改密前不能进入其他受保护页面，完成后可正常返回应用。

## Out of Scope

- 新增或删除后端配置字段、迁移数据库或改变模型路由算法。
- 重构任务日志、项目选择器、写作台章节工具栏或全站视觉语言。
- 新增暗色主题、新依赖或通用设置框架。
- 修改模型供应商上游协议、拉取模型规则或成本计算逻辑。
