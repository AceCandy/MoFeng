# 统一为单一暖纸浅色主题

## Goal

将前端从“浅色/暗色主题 + 固定夜色场景”收敛为唯一的暖纸浅色视觉体系，让登录、首页、项目与写作页具有一致的白天皮肤，不再出现大块近黑色容器或用户可切换的暗色分支。

## Background

- 现有 `frontend/src/main.ts:15-55` 根据本地存储和系统偏好解析 `light | dark | system`，`frontend/src/components/shared/AppShell.vue:33-49,349-376,586-590` 提供主题切换及重复的系统监听。
- `frontend/src/assets/styles/tokens.css:189-270` 同时定义固定夜色 token 和暗色主题 token；夜色应用到首页 Hero、认证页和写作台。
- 用户已明确选择只保留一套暖纸浅色皮肤，不保留固定夜色场景。

## Requirements

1. 页面始终使用现有暖纸浅色 token，不再根据系统偏好或本地存储切换主题。
2. 移除顶栏的昼/夜主题切换入口及其状态、事件和媒体查询监听；其他顶栏功能和键盘/无障碍行为保持不变。
3. 首页 Hero、登录/注册、写作台页底、顶栏、章节侧栏、章节工具带和助手面板改用纸色表面层级，不保留大面积近黑背景。
4. 保留现有信息架构、表单、业务操作、响应式布局和朱砂主操作色；只移除为夜色场景服务的装饰与样式分支。
5. 删除无引用的 `--md-night-*` token、暗色 token 覆盖、暗色专用选择器与 `auth-night.css`；不保留无效兼容层。
6. 更新 `DESIGN.md`、前端规范和相关测试，使“单一暖纸浅色”成为可执行合同。
7. 原有用户浏览器中的 `mofeng-theme-preference` 残留值不需要迁移或清理；新版不再读取它，界面始终渲染浅色。

## Acceptance Criteria

- [ ] 无论操作系统偏好或浏览器中是否存在旧主题值，根节点都以唯一浅色主题渲染，首屏无主题闪烁。
- [ ] 顶栏不再显示昼/夜切换按钮，代码不再读写 `mofeng-theme-preference`、监听 `prefers-color-scheme` 或派发 `theme-changed`。
- [ ] 受影响界面不再引用 `--md-night-*`，全局样式不再包含 `[data-theme='dark']` 视觉分支。
- [ ] 首页、登录/注册和写作台的主要表面在桌面及移动端均为暖纸浅色，文字、焦点、按钮、进度与状态保持可辨认，没有横向溢出。
- [ ] 登录、注册、项目导航、章节选择/阅读、写作工作流和助手面板功能无回归。
- [ ] 受影响的静态合同测试、前端 lint、类型检查和全量 Vitest 通过；桌面与 390×844 浏览器回归通过。

## Out of Scope

- 不新增或重新设计暗色主题。
- 不改动文案、业务流程、后端 API 或数据结构。
- 不借机重构与主题无关的组件、布局或样式。

## Technical Notes

- 优先在 `frontend/index.html` 静态标记 `data-theme="light"`，避免运行时主题初始化与首屏闪烁。
- 纸色替换使用现有 `--md-background`、`--md-surface*`、`--md-on-surface*`、`--md-outline*`、`--md-primary*` 和 `--md-elevation-paper-*`，不新增同义 token。
- 删除全局 CSS 前必须确认所有项目自有引用已替换，并在浏览器检查受影响页面。
