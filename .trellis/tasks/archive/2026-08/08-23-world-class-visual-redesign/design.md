# 技术与视觉设计

## 方向合同

- **THESIS**：墨风是一册正在排演的长篇作品，不是仿古书房，也不是通用 AI 面板；拒绝“暖纸 + 红章 + 卡片墙”。
- **OWN-WORLD**：群青结构面、冷白工作面、近黑正文、朱红 cue、极少量荧黄批注；直角模块、场次编号、对位线和裁切标记组成组件语法。
- **STORY**：作者进入后先认出正在写的作品和下一步，再进入灵感、档案或写作；AI 提示始终从属于作者确认。
- **FIRST VIEWPORT**：桌面工作区使用严格分舞台构图，左侧群青继续创作面占约 42%，右侧冷白项目清单占约 58%，全局导航跨越两面，主动作只出现一次。
- **FORM**：七个受众文化候选中的第六方向“剧场排演提示本”，概念种子 `94f236b2`；选择严格分舞台构图。图像草图因环境 API key 401 未生成，真实浏览器渲染为视觉证据。
- **FINISH**：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, and DESIGN.md

## 边界

- 仅修改前端模板、样式、少量纯 UI 状态与测试；不修改请求载荷、接口、权限和数据库。
- 复用 Vue 3、Naive UI、现有 Lucide 图标、CSS Grid/Flex、CSS 自定义属性和原生过渡。
- 不新建设计系统运行时，不添加主题切换器，不引入新依赖。
- 以现有 DOM 和 class 为兼容边界；先通过新令牌和单一权威样式层替换视觉，再做页面必要结构调整。

## 视觉系统

### 色彩

- `stage`：高饱和群青，承担导航、结构区和当前上下文，不用于长文正文底。
- `paper`：略带冷灰的白，承担表单、正文和数据工作面。
- `ink`：近黑，只用于文字、细线和必要控件，不形成大块暗场。
- `cue`：朱红，只用于关键动作、错误和当前 cue。
- `note`：酸性荧黄，只用于临时、待确认、提醒，面积受限。
- 状态同时使用文字、图标或形状，不能只依赖颜色。

### 字体与形态

- 正文和表单改为系统中文无衬线栈，长文阅读允许专用宋体正文栈以保护阅读舒适度。
- 展示标题使用系统收窄无衬线候选栈并控制字距；不下载新字体。
- 控件圆角 0–6px，取消胶囊、仿古双线框和印章形态。
- 边界以 1px 对位线、局部 3px cue 线和块面错位建立层级，阴影只用于弹层。

### 动效

- 全站唯一签名动效是 cue 线进入/对位：使用 `transform` 与 `opacity`，140–280ms。
- 主动作按下表现为真实位移；列表 hover 只改变线、底色或轻微平移。
- `prefers-reduced-motion: reduce` 下立即到终态。

## 共享实现

1. `tokens.css` 作为唯一色彩、字体、形状、阴影和层级来源。
2. `main.css` 保留既有导入顺序，最后加载共享 `world-class.css`；认证专属规则由异步 `AuthLayout.vue` 加载 `world-class-auth.css`，在保持覆盖顺序的同时避免把路由独占 CSS 压进入口 bundle。
3. `AppShell` 保留业务状态和事件，重组导航视觉与内容框架；`AuthLayout` 建立认证专属舞台。
4. `App.vue` 的 Naive UI overrides 与新令牌取值一致。
5. 共享按钮、输入、标签、弹层、表格和空状态统一到 cue-book 语法。

## 响应式与可访问性

- 继续使用 1200 / 834 / 833 断点；手机端将分舞台纵向叠放，导航变可横向扫读的稳定控制带。
- 所有文本容器补 `min-width: 0` 与必要的 `overflow-wrap`；长标题、长 URL 和错误文案不得撑破视口。
- 抽屉与弹层保留 Escape、焦点管理和 `aria-hidden`；键盘焦点使用高对比双层 outline。
- 关键按钮和图标触控目标至少 44px。

## 兼容、回滚与风险

- 新世界优先通过令牌和最终覆盖层落地，回滚可直接恢复单次工作提交。
- 最大风险是旧 CSS 多层覆盖；通过一次性检索 `!important`、浏览器 computed style 和最后加载的单一迁移层控制。
- 第二风险是大型页面将业务与 scoped CSS 混在同一文件；模板调整保持小范围，复杂业务逻辑不触碰。
- 视觉图片不是运行时依赖；图像草图失败不会影响页面功能或交付。
