# 技术设计

## 1. 设计目标

本任务不是第二次视觉重构，而是一次“运行时 P1 复现 + 旧级联收口”。现有剧场提示本界面、业务 DOM、路由和交互合同保持不变；只有真实浏览器复现失败的 P1 才修复，同时删除已被最终覆盖层完整取代的旧视觉声明。

## 2. 边界

- 仅修改前端样式、必要的页面模板小调整、E2E fixture/测试和任务文档。
- 不修改后端、API、数据结构、创作状态机、查询缓存或跨设备上下文合同。
- 不新增依赖、设计 token、主题、全局组件或截图框架。
- 长文阅读宋体、描红楷体、AI provenance 和章节稿纸状态属于明确例外，不纳入旧主题清理。

## 3. 验证先行

新增一个聚焦的全站 P1 浏览器合同，复用现有 Playwright fixture 与双视口配置：

1. 访问登录、注册、工作台、灵感、详情、写作台、设置、管理、管理员详情九页。
2. 受保护页使用现有 `e2e-token` 与 fixture 的 user/admin 模式，不创建持久用户。
3. 稳定后断言无横向溢出、关键主动作可见、最终 computed style 属于群青/冷白无衬线体系。
4. 对详情长内容、灵感长对话和写作长章节断言滚动容器 `scrollHeight > clientHeight` 时可滚动到末尾，且末尾内容可见。
5. 在桌面和 Pixel 7 执行；补一条低高度或 200% 缩放的最小用例，只在能稳定复现时保留。

该合同先在改动前通过，作为等价输出基线；若真实 P1 能复现，则测试先失败，再做最小修复。

## 4. CSS 清理策略

### 4.1 认证批次

- 删除最终层直接隐藏的 AuthIntro 装饰节点样式；若模板节点没有语义或布局作用，同时删除对应纯装饰 DOM。
- 从 Login/Register scoped CSS 删除被 `world-class-auth.css` 完整接管的暖纸背景、panel 纹理/阴影/旧字体属性。
- 保留表单尺寸、验证、布局、position/z-index/overflow 与交互状态。

### 4.2 应用页面批次

- 以 `world-class.css` 中页面级选择器为清单，逐属性核对工作台、灵感、详情、写作台、设置和管理页面的旧声明。
- 只删除最终层在同一状态和断点下完整覆盖的声明；无法证明等价的规则保留并记录，不新增反向覆盖。
- 优先删除成片无效规则；单个无害注释或变量名不为“清理完整”而扩大 diff。

## 5. 级联与兼容合同

- `world-class.css` 继续是 `main.css` 最后一个全局 partial。
- `world-class-auth.css` 继续由异步 `AuthLayout.vue` 加载，避免推高入口 CSS。
- 1200 / 834 / 833 响应式断点、稳定 class、ARIA 文案、路由与测试 selector 保持不变。
- 删除只减少无效 CSS，不改变最终 computed style；确有 P1 修复时，变化必须对应一条验收标准。

## 6. 回滚

- 验证合同、认证清理、应用页清理、真实 P1 修复分批实施和复核。
- 任一批出现截图、computed style、axe、滚动或业务 E2E 回归时，只回滚该批，不用新增补丁层掩盖问题。
- 不删除 `world-class` 覆盖层，因此整体回滚不涉及主题迁移或后端数据。
