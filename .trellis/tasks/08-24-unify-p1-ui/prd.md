# 统一全站 P1 UI 与交互

## Goal

处理全站 UI 审查中经运行时级联、现有响应式合同与历史验证证据复核后仍成立的全部 P1 问题，使作者在桌面和移动端稳定识别当前项目、唯一下一步和配置阻断项，同时不回归已经落地的“剧场排演提示本”视觉系统。

## Background

- 用户要求处理审查报告中的全部 P1。
- 审查快照位于 `.impeccable/critique/2026-08-24T03-25-51Z__frontend-src.md`，原报告将视觉漂移、固定视口、主任务竞争和设置恢复路径列为 P1。
- 前置任务 `08-23-world-class-visual-redesign` 已声明九个主页面统一到群青/冷白的剧场提示本体系，并以 1440×900、Pixel 7、axe、26 项 Playwright、类型检查、单元测试和生产构建完成验证。
- 前置任务 `08-24-interaction-experience-design` 已实现跨设备创作上下文恢复、唯一主动作和任务结果回跳；本任务不得倒退这些合同。

## Confirmed Facts

### C1. “全站仍显示暖纸、宋楷、印章”不是运行时 P1

- `frontend/src/assets/main.css` 最后加载 `world-class.css`，覆盖此前所有遗留视觉层。
- `frontend/src/components/shared/AuthLayout.vue` 额外加载 `world-class-auth.css`。
- `world-class.css` / `world-class-auth.css` 使用更高特异度与必要的 `!important`：移除认证页纹理与阴影、隐藏印章装饰、将 UI chrome 改为无衬线，并统一设置、管理、详情、写作台工作面。
- 前置任务最终截图中的登录、灵感与设置页面已显示群青/冷白体系，不是组件 scoped CSS 单独呈现出的暖纸界面。
- 当前遗留 scoped CSS 属于维护性债务：它会误导源码审查，但没有证据证明它构成当前用户可见 P1。

### C2. “固定视口导致核心内容不可滚动”不是已证实的 P1

- `--app-viewport-unit` 在支持环境中使用 `100dvh`，兼容动态浏览器栏和软键盘视口。
- 详情页由 `useShellSectionContent` 给全部内容面注入 `overflow-y-auto overscroll-contain`；章节列表与阅读面有各自明确的内部滚动区。
- 灵感消息区、排演脉络分别具有内部 `overflow-y:auto`；输入区固定在主任务末端。
- 写作台正文 `.writing-workspace__body` 是内部滚动所有者；移动端解除桌面高度链并让页面自然展开，抽屉独立滚动。
- 前置任务已验证桌面与 Pixel 7 无横向溢出、抽屉可达；当前连续创作提交未移除上述滚动合同。

### C3. 主任务和设置恢复已有专门实现

- 连续创作任务已经要求并实现六个核心页面唯一主动作、最近语义位置恢复和后台任务结果回跳。
- 设置页首屏已展示能力状态、主文本模型、主检索模型和供应商启用情况；四个配置域使用 URL 深链、roving tabindex 和未保存确认。
- 是否进一步减少顶栏/灵感辅助信息，或把设置健康摘要改成阻断项直达列表，属于产品取舍，不是由现有证据可直接判定的故障修复。

## Requirements

### R1. 只修复复核后仍成立的用户可见 P1

- 不因组件中存在被最终层覆盖的旧 CSS，就重做已经正确显示的视觉页面。
- 不移除桌面内部滚动工作区，除非真实浏览器复现内容不可达、软键盘遮挡或 200% 缩放裁切。
- 不改变后端 API、数据模型、创作状态机、跨设备上下文恢复或任务回跳。

### R2. 若纳入遗留 CSS 治理，必须以等价输出为边界

- 本任务纳入遗留视觉 CSS 治理，与真实可复现 P1 一起处理。
- 只删除或迁移已被 `world-class.css` / `world-class-auth.css` 完整覆盖的旧视觉声明。
- 不引入新设计系统、主题、依赖或兼容层。
- 每批删除必须以 computed style、截图和现有测试证明用户可见输出等价。

### R3. 验证优先于视觉再设计

- 使用现有 E2E fixture 覆盖九页桌面与 Pixel 7，而不是创建真实用户或修改开发数据。
- 对详情长内容、灵感长对话、写作长章节增加或复用最小可运行检查，确认唯一滚动所有者与内容可达。
- 使用 200% 缩放、低高度视口和移动软键盘等价场景验证此前只有源码推断的风险。

## Acceptance Criteria

- [x] 每个保留为 P1 的问题都有当前运行时复现步骤，不能只引用被最终样式层覆盖的 scoped CSS。
- [x] 九个主页面在 1440×900 与 Pixel 7 下保持同一剧场提示本视觉世界，无暖纸、印章、UI 宋楷字体回归。
- [x] 详情长内容、灵感长对话、写作长章节均可到达末尾；桌面只有预期内部滚动，移动端无内容裁切或横向溢出。
- [x] 工作台、灵感、详情、写作台仍各有一个与当前状态匹配的主动作，跨设备恢复和任务回跳不退化。
- [x] 设置首屏明确显示是否可开始创作及阻断原因；现有 query 深链、键盘切换和未保存确认不退化。
- [x] 不新增前端依赖，不修改后端接口或数据结构。
- [x] 类型检查、相关单元测试、现有桌面/移动 E2E、axe、生产构建及一次 Impeccable detector 通过。
- [x] 调试服务和浏览器会话在验证结束前关闭，临时截图/fixture 数据不进入仓库。

## Out of Scope

- 新主题、暗色模式、全新导航体系或第二套设计 token。
- 修改创作业务流程、AI 能力、模型路由含义或后台权限。
- 为“看起来更干净”而重写稳定组件结构。
- 当前报告中的 P2/P3 可访问性、表单和文案细节。

## Key Decision

- 用户选择同时处理真实可复现 P1 与被最终覆盖层遮住的遗留暖纸、宋楷、印章视觉 CSS。
