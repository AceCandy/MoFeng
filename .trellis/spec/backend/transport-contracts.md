# Generated Transport Contract

## 1. Scope / Trigger

Apply this contract when changing a FastAPI route, request/response Pydantic model,
OpenAPI generation, a migrated frontend API DTO, task SSE payloads, or transport
contract CI. It currently owns task list/detail/snapshot/events, canonical Chapter and
NovelProject reads, novel summaries/sections, and ordinary admin JSON DTOs.

Dynamic dictionaries without an accurate Pydantic model, file responses, and
application-specific SSE framing remain outside generated ownership until their
backend contract is made explicit.

## 2. Signatures

Canonical artifact commands:

```text
cd backend
python -m app.openapi_export --output openapi.json
python -m app.openapi_export --check --output openapi.json

cd frontend
npm run api:generate
npm run api:check
```

Committed release unit:

```text
backend Pydantic models
  -> backend/openapi.json
  -> frontend/src/api/generated/schema.d.ts
  -> src/api domain aliases
  -> queries/components
```

Task state payloads:

```text
snapshot -> BackgroundTaskSnapshotResponse(schema_version=1)
task     -> BackgroundTaskEventResponse(schema_version=1)
reset    -> BackgroundTaskCursorResetResponse(schema_version=1)
error    -> bounded transport Error; never enters task state
```

Semantic PR gate:

```text
oasdiff 1.26.1 breaking <base-openapi.json> backend/openapi.json \
  --fail-on ERR --format githubactions
```

CI downloads `oasdiff_1.26.1_linux_amd64.tar.gz` and accepts only SHA256
`ea0007fe536c7915785f754885d2afdb11352d6a14531950edf9d601a2baa674`.
On pull requests, it verifies `${base_sha}:backend/openapi.json` with
`git cat-file`, extracts it with `git show` into `$RUNNER_TEMP`, and removes the
temporary artifact with an EXIT trap. Only a genuinely absent first baseline may
skip semantic comparison; an unreadable existing baseline fails closed.

## 3. Contracts

- Pydantic request/response models are the wire source of truth. Ordinary JSON routes
  declare `response_model=` and must not publish a schema more precise than runtime
  behavior.
- `backend/openapi.json` is generated by `app.openapi_export`. Export does not start
  ASGI lifespan, connect to a database, run bootstrap, or read machine-specific
  metadata. Canonical JSON is UTF-8, sorted, deterministic, and has one trailing
  newline. `--check` is read-only.
- Application operation IDs use the compatibility-preserving deterministic generator.
  Every operation ID is present and unique. An internal handler rename first pins the
  old explicit `operation_id`; a real public rename follows compatibility rollout.
- `frontend/src/api/generated/schema.d.ts` is owned only by
  `openapi-typescript 7.13.0`. Keep its generated header and do not post-process it.
- Migrated API modules preserve readable exported names with indexed aliases, for
  example `type Chapter = components['schemas']['Chapter']`. They must not repeat
  object fields in an interface or object-literal alias.
- A dynamic JSON field typed as `unknown` stays unknown at the wire boundary. Narrow it
  once in a domain utility/decoder before UI use; do not weaken the generated alias or
  reintroduce a hand-written transport mirror.
- Identity fields whose backend validator is stricter than generated TypeScript's
  `string` must repeat that format check at the runtime boundary. For example, a
  canonical UUID validator must reject a same-length non-UUID before the payload enters
  Vue Query or an actor; a length check alone does not preserve the Pydantic contract.
- Task HTTP snapshot and SSE snapshot use the same decoder. Snapshot/task/reset
  validate `schema_version`, reducer-critical cursor/task fields, and required shapes
  before invoking handlers. A scoped snapshot must echo the requested
  `stream_type`/`stream_id`; an unscoped snapshot must keep both absent/null. Unknown
  outer events are ignored. An invalid stream first fetches one same-scope snapshot;
  an invalid recovery snapshot stops SSE state and yields to the existing polling
  result.
- Every task-stream callback is bound to the current, non-aborted connection identity.
  A callback queued by a previous user/scope/connection is ignored even when its
  payload is otherwise valid.
- Schema, OpenAPI artifact, generated TypeScript, aliases, decoder, and relevant tests
  ship and roll back together. Required-field additions, response-field removals, enum
  narrowing, and type narrowing require an explicit compatibility window.
- CI runs both byte-drift checks and semantic breaking checks. Neither substitutes for
  the other. The `oasdiff` release archive is version- and SHA256-pinned and never uses
  the upload/open mode.

## 4. Validation & Error Matrix

| Condition | Required result |
| --- | --- |
| Missing or duplicate operation ID | OpenAPI build fails |
| Route contains zero or multiple HTTP methods | Stable ID generation fails; split the route |
| OpenAPI bytes differ from the committed artifact | `app.openapi_export --check` exits non-zero without writing |
| Generated TypeScript bytes differ | `openapi-typescript --check` exits non-zero without writing |
| Migrated DTO is restored as an interface/object literal | AST ownership check exits non-zero with file and line |
| Task payload is not an object or lacks an integer version | Decoder returns `malformed`; no handler/state mutation |
| Task payload version is not `1` | Decoder returns `unsupported_version`; no handler/state mutation |
| Snapshot scope differs from the requested scope | Decoder returns `malformed`; no handler/state mutation |
| Identity has the expected length but is not a canonical UUID | Decoder returns `malformed`; no cache/actor mutation |
| Aborted or superseded connection delivers a late callback | Ignore it without changing snapshot or cursor |
| Unknown outer task SSE event | Ignore it without changing state or cursor |
| First malformed/unsupported task stream payload | Fetch one snapshot for the same authenticated scope |
| Recovery snapshot is malformed/unsupported | Abort SSE, clear SSE override/cursor, retain polling fallback |
| PR base has no canonical OpenAPI artifact | Print the one-time baseline-introduced notice; run all other gates |
| PR base commit/artifact is unreadable after baseline exists | Fail closed |
| `oasdiff` reports `ERR` | CI fails; WARN/INFO remain review output |

## 5. Good / Base / Bad Cases

- Good: add a Pydantic response field, regenerate both artifacts, expose it through the
  existing domain alias, and pass byte plus semantic gates.
- Good: a task event with valid version and cursor is decoded once and then reaches the
  reducer; an old cursor is still ignored by the reducer.
- Good: workflow run, root job, successor, and command identities are checked as
  canonical UUIDs before reconciliation.
- Base: a new outer task event kind arrives. Older clients ignore it and continue from
  their current cursor.
- Base: a backend dynamic dictionary remains `Record<string, unknown>` in generated
  TypeScript and a focused domain utility narrows only the fields the UI consumes.
- Bad: edit `schema.d.ts`, duplicate `Chapter` fields in `admin.ts`, cast
  `message.data as BackgroundTaskEvent`, or disable a drift gate during a tool outage.
- Bad: accept an identity because it contains 36 characters when the backend requires a
  canonical UUID.
- Bad: claim an SSE text frame is a JSON response body in OpenAPI, or generate a fake
  Pydantic model for a dynamic/file endpoint merely to increase coverage.

## 6. Tests Required

- Backend OpenAPI tests assert deterministic bytes, hermetic export, path/operation/schema
  counts, operation-ID golden hash, uniqueness, extra SSE components, and rejection of
  unsupported semantic-diff constructs.
- Task transport tests cover valid snapshot/task/reset, HTTP snapshot reuse, malformed
  shapes, missing/unsupported versions, response-scope mismatch, unknown outer events,
  no handler mutation, same-scope recovery, superseded-connection callbacks, and
  repeated-failure polling fallback.
- Ownership tests prove interfaces and nested object-literal aliases fail while indexed
  generated aliases, canonical re-exports, and derived `Omit<generated, ...>` aliases pass.
- Frontend type-check and lint run after each alias domain cutover.
- Frontend decoder tests include same-length non-canonical values for every UUID
  identity used to address a stream, run, root job, successor, or command.
- CI compares a PR base artifact with the current artifact using the pinned binary.
  Fixtures or a controlled local check prove response-field removal and required request
  addition are blocking changes.

## 7. Wrong vs Correct

### Wrong

```ts
export interface Chapter {
  chapter_number: number
  title: string
}

handlers.onTask(message.data as BackgroundTaskEvent)
```

This creates a private wire contract and lets untrusted JSON mutate state without
runtime validation.

### Correct

```ts
export type ChapterWorkflowSnapshot =
  components['schemas']['ChapterWorkflowSnapshot']

const canonicalUuid =
  /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/

const decodeRunId = (value: unknown): string => {
  if (typeof value !== 'string' || !canonicalUuid.test(value)) {
    throw new ChapterWorkflowContractError('malformed', 'run_id')
  }
  return value
}
```

Generated fields retain single ownership, while the runtime decoder protects the
untrusted SSE boundary.
